# Situation 4

อธิบายว่า API Key หรืออะไรก็ตามที่เป็น Credentials ควรเก็บไว้เป็นความลับ เหมือนเป็นกุญแจเข้าบ้าน ถ้าหากใครมีกุญแจเราก็จะสามารถเข้าบ้านเราได้ตลอดเวลาและขโมยของในบ้านไปได้ ดังนั้นเราไม่ควรนำ API Key หรือ Credentials อื่นๆ ไปใส่ไว้ในโค้ด หรือในส่วนที่ใครก็ตามสามารถเห็นได้ ส่วนเรื่องของ URL ของ 3rd Party ก็เหมือนกัน เพราะอาจมีคนใช้ในการโจมตีได้ หรือยิ่งกว่านั้น หากเป็น URL ที่เสียค่าใช้จ่าย แล้วมีคนไปเรียกใช้ ก็จะทำให้เราเสียดายได้

แล้วเราจะเก็บไว้ที่ไหน เราสามารถเก็บไว้ในสิ่งที่เรียกว่า Environment Variable ของเครื่องได้ และเขียนโค้ดเพื่อดึงค่ามา หากเป็นค่าที่ซับซ้อน เราอาจจะเขียนเป็น Config File เช่น JSON, YML แล้วเก็บชื่อของไฟล์ไว้ใน Environment Variable ได้เหมือนกัน แล้วดึงมาใช้เพื่อ Load Config
