## การดูคำตอบ

สามารถดูคำตอบของแต่ละข้อได้ใน Folder: `situation_{ข้อคำถาม}`

โดยคำตอบจะใช้ชื่อว่า `situation_{ข้อคำถาม}_answer.md`

ยกเว้นข้อ 1 ที่มีคำถามย่อย จะแบ่งออกเป็นตามข้อย่อย โดยใช้ suffix `_q{ข้อย่อย}` เช่น `situation_1_answer_q1.md`

## Prompts

ข้อ 1 และ 3 จะมี `prompts.md` ที่ระบุคำถามที่ใช้ถาม AI
